# SECURITY.md
## ATOR Security Policy

### Reporting
For institute repositories, do not open public issue for sensitive data leak. Contact owner directly via GitHub @DeborahRamMozes.

### Branch Protection
All `main` branches must be under `ATOR-main-archive-protection` ruleset. Direct pushes to main are not allowed. All changes via PR with 1 approval.

### No Deletion Law
Any deletion of canon, research, protocol, criticism, or Black Paper material must record: repository, path, reason, human approval, issue/PR ref, replacement path, backup SHA, author, reviewer.
